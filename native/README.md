# Island Lab для Windows

Island Lab — приложение Tauri 2 с WebView2. Интерфейс хранится в корне репозитория и копируется в `native/dist` перед сборкой. Snowy New Year запускается отдельным процессом и принимает команды настроек через локальное окно Win32.

## Сборка

Нужны Windows 10/11, WebView2, Node.js 20+ и Rust 1.95+. Для MSVC установите Visual Studio Build Tools с компонентом Desktop development with C++. Сборку также проверили на `x86_64-pc-windows-gnu`.

Из корня репозитория запустите PowerShell и выполните

```powershell
.\scripts\test-windows.ps1
```

Скрипт проверяет веб-код и Rust, собирает `island-lab.exe` и выводит путь к нему. Для проверки снегопада положите совместимый `Snowy New Year.exe` рядом с Island Lab или укажите его во вкладке Snowy New Year. Совместимая сборка входит в комплект из релиза Island Lab.

Для разработки с Tauri CLI выполните `npm install` и `npm run dev` в папке `native`.

## Интеграции Windows

- Совместимые плееры подключаются через Windows Media Sessions. При подключении доступны название, исполнитель, управление и позиция, если плеер её публикует.
- Волна системного звука использует WASAPI loopback. Захват включается отдельным переключателем, уровень звука передаётся в интерфейс для визуализации.
- Print Screen захватывает монитор под курсором. Редактор сохраняет PNG в папку «Изображения → Island Lab».
- Режим размещения под обычными окнами можно проверить в настройках. Таймер автоматически возвращает окно, если режим не подтверждён. Подробнее в [описании режима](../DESKTOP_LAYER_TEST.md).
