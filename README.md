## Возможности

| | |
| --- | --- |
| **Музыка** | Очередь локальных файлов, управление совместимыми плеерами Windows и аудиоволна. Для системного звука есть отдельный переключатель захвата. |
| **Слова песни** | Текущая строка подсвечивается и прокручивается за треком. Нажатие на строку перематывает песню. Источник — LRCLIB или ваш файл `.lrc`. |
| **Погода** | Выбор города, температура и ветер. Данные Open-Meteo обновляются раз в час и по кнопке. |
| **Скриншоты** | Print Screen открывает снимок монитора под курсором в редакторе. Можно обрезать, рисовать, отменять правки и сохранять в PNG. |
| **Блокнот** | Несколько заметок с локальным автосохранением. |
| **Snowy New Year** | Запуск совместимого Snowy из вкладки Island Lab и управление снегопадом, снежными шапками, лепкой и интенсивностью. |

## Быстрый старт

1. Скачайте [Island-Lab-windows-x64.zip](https://github.com/Deenfoool/island-lab/releases/latest/download/Island-Lab-windows-x64.zip) для Windows 10 или 11 (x64, с WebView2).
2. Распакуйте ZIP и запустите `Island Lab.exe`. Установка не нужна.
3. Раскройте капсулу. Добавьте музыку кнопкой **+** или подключите плеер Windows в настройках. Там же можно выбрать город для погоды.

Для снега скачайте [комплект со Snowy New Year](https://github.com/Deenfoool/island-lab/releases/latest/download/Island-Lab-with-Snowy-windows-x64.zip). В нём оба приложения лежат рядом. Откройте вкладку **Snowy New Year** и нажмите **«Запустить Snowy New Year»**. Если совместимая копия уже запущена, настройки появятся сразу.

## Сборка из исходников

Island Lab использует Rust, Tauri 2 и WebView2. Запуск сборки и тестов на Windows описан в [руководстве разработчика](native/README.md).

Настройки и заметки хранятся на устройстве. Open-Meteo получает запросы для выбранного города, а поиск в LRCLIB отправляет название трека и исполнителя по кнопке «Найти слова». На изображениях показаны демонстрационные данные.
